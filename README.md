# Buddy and the Bible

An archive of Buddy Payne's morning devotionals.

**<https://buddy-and-the-bible.web.app>**

Buddy has sent a short devotional to his family most weekday mornings — a
passage of scripture and a few paragraphs on it. This site collects them so
they can be read, searched and kept, rather than scrolling away in a group
message.

Each devo is shown the way it arrived: as a message in a thread. There are
**203 of them**, from January to October 2026, transcribed from screenshots
of the original messages.

You can search the devos by word or by date, browse a
[scripture index](https://buddy-and-the-bible.web.app/scripture/) of all 345
verses he cites, and see at a glance which days he wrote.

## Running it

```sh
npm install
npm start     # http://localhost:8080
npm run build # writes the static site to _site/
```

Built with [Eleventy](https://www.11ty.dev/) and hosted on Firebase.
